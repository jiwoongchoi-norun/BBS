# BBS 프로젝트 진행 보고서

## 1. 개요

본 프로젝트는 Node.js, Express, EJS, OracleDB를 사용한 게시판 과제입니다. 기본 게시판 기능을 완성한 뒤 bcrypt, 댓글/대댓글, 파일업로드, 좋아요/싫어요, SQL bind variable 적용까지 보강했습니다.

## 2. 현재 완료 기능

- 게시글 목록, 검색, 페이징
- 게시글 작성, 읽기, 수정, 삭제
- 조회수 증가
- 로그인, 로그아웃, 회원가입, 회원정보 수정
- express-session 기반 세션 처리
- bcrypt 비밀번호 저장
- 기존 SHA-512 + salt 계정 자동 bcrypt 마이그레이션
- 댓글 작성
- 대댓글 작성
- 댓글 삭제
- 게시글 좋아요/싫어요
- 동일 사용자의 중복 추천 방지
- 좋아요/싫어요 취소 및 전환
- 추천 후 조회수 증가 방지
- 파일 업로드와 다운로드
- 작성자 권한 체크
- 주요 SQL bind variable 적용
- 기본 입력값 검증
- Bootstrap 5 기반 화면 정리
- ESLint, Prettier, app load 검증

## 3. 주요 개선 내용

### 인증과 비밀번호

- 로그인 성공 시 `req.session.user`에 사용자 ID, 이름, 이메일을 저장합니다.
- 신규 비밀번호는 bcrypt로 저장합니다.
- 기존 SHA-512 + salt 계정은 로그인 성공 시 bcrypt로 자동 재암호화합니다.
- `LOGIN.PASSWORD_ALGO`로 비밀번호 해시 방식을 구분합니다.

### 게시글

- `BBS.OK = 0` 방식으로 soft delete합니다.
- 게시글 수정/삭제는 로그인 사용자와 작성자가 같을 때만 허용합니다.
- 게시글 읽기 시 `BBS.VIEW_COUNT`를 증가시킵니다.
- 좋아요/싫어요 후 read 화면으로 돌아오는 내부 이동은 조회수를 증가시키지 않습니다.

### 댓글

- `BBSW` 테이블을 사용합니다.
- `PARENT_NO`, `DEPTH`로 대댓글을 표현합니다.
- 댓글 삭제는 작성자 본인만 가능합니다.

### 좋아요/싫어요

- `BBS_REACTION` 테이블에 사용자별 추천 기록을 저장합니다.
- `(BBSNO, USER_ID)` 기본키로 한 게시글에 한 사용자당 하나의 반응만 허용합니다.
- 같은 반응을 다시 누르면 취소합니다.
- 반대 반응을 누르면 기존 반응을 전환합니다.

### 파일업로드

- `multer`로 파일을 `uploads/bbs`에 저장합니다.
- `BBS_FILE`에는 원본 파일명, 저장 파일명, 경로, 크기, MIME 타입을 저장합니다.
- 다운로드 시 DB의 원본 파일명을 기준으로 내려줍니다.

## 4. 검증 결과

최근 검증 기준:

- `npm run lint`: 통과
- `npm run format:check`: 통과
- `npm run verify:app`: 통과
- 좋아요/싫어요 조회수 검증: 일반 읽기 후 조회수 1, 좋아요/취소 후에도 조회수 1 유지
