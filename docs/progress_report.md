# BBS 프로젝트 진행 보고서

## 1. 프로젝트 개요

본 프로젝트는 Node.js, Express, EJS, OracleDB를 기반으로 하는 게시판 과제 프로젝트이다. 교수님 수업자료와 과제 요구사항을 기준으로 기본 게시판 흐름을 복구하고, 제출 전 미완료 기능과 보안 개선을 단계적으로 보완하는 방향으로 진행 중이다.

## 2. 현재 구현 결과

현재 코드 기준 구현 범위는 다음과 같다.

- 게시글 목록
- 글쓰기
- 글읽기
- 글수정
- 글삭제
- 검색
- 조회수
- 로그인
- 로그아웃
- 회원가입
- 회원정보 수정
- 세션 처리
- Bootstrap 5 기반 반응형 UI
- `.env` 기반 환경설정 분리
- `SESSION_SECRET` 환경변수 사용
- 게시글 soft delete 처리
- VSCode 디버깅 설정
- ESLint/Prettier/npm scripts 기반 검증 루틴

위 기능을 기준으로 기본적인 게시판 사용 흐름은 시연 가능한 상태이다.

## 3. 주요 개선 사항

### 3.1 환경설정 분리

- DB 접속 정보는 `.env` 기반으로 분리되어 있다.
- `SESSION_SECRET`은 코드에 직접 작성하지 않고 환경변수로 관리한다.
- 필수 환경변수가 없으면 애플리케이션 실행을 중단하도록 처리되어 있다.

### 3.2 세션 처리

- 로그인 성공 시 `req.session.user`에 사용자 정보를 저장한다.
- 세션에는 사용자 식별에 필요한 최소 정보만 저장한다.
- 비밀번호는 세션에 저장하지 않는다.

### 3.3 로그인 필요 기능 보호

`routes/bbs.js`에 `requireLogin()` 형태의 공통 확인 로직이 있다. 현재 다음 기능에 적용되어 있다.

- 글쓰기 화면
- 글 저장
- 글수정 화면
- 글수정 저장
- 글삭제
- 회원정보 수정 저장

### 3.4 게시글 soft delete

- 게시글 삭제 시 실제 `DELETE`를 실행하지 않는다.
- `BBS.OK = 0`으로 상태만 변경한다.
- 목록, 상세, 수정 조회에서는 `OK = 1`인 게시글만 대상으로 한다.

### 3.5 검색 조건

- 제목 검색
- 내용 검색
- 작성자 검색
- 제목 + 내용 검색

검색 기능은 구현되어 있으나, 검색어 SQL bind variable은 아직 적용되지 않았다.

### 3.6 조회수

- `BBS.VIEW_COUNT` 컬럼이 추가되어 있다.
- 상세 조회 시 조회수가 1 증가한다.
- 목록과 상세 화면에 조회수가 표시된다.
- 기존 DB용 `scripts/add-view-count.sql`이 있다.

### 3.7 Bootstrap 5 UI

- 공통 head와 navigation partial을 사용한다.
- 내비게이션은 모바일에서 접힘 메뉴로 동작한다.
- 게시글 테이블은 작은 화면에서 가로 스크롤로 overflow를 처리한다.
- 작성, 수정, 로그인, 회원가입, 회원정보 수정 화면은 동일한 카드 스타일을 사용한다.

## 5. DB 구성

현재 스키마 기준 주요 객체는 다음과 같다.

- `LOGIN`
- `BBS`
- `BBS_SEQ`

현재 데이터 구조는 기본 인증, 게시글, 조회수 기능을 충족한다. 댓글과 파일 업로드를 위해서는 추가 테이블 또는 컬럼 설계가 필요하다.

## 6. 현재 남은 과제

1. bcrypt를 이용한 비밀번호 암호화 적용
2. SQL bind variable 적용
3. 페이징 구현
4. 댓글 구현
5. 파일 업로드 구현
6. 작성자 권한 체크
7. 서버 측 입력값 검증
8. 자동 테스트 추가

## 7. 기술적 한계 및 리스크

- 비밀번호가 아직 평문 저장 방식이다.
- SQL 문자열 직접 결합이 남아 있어 SQL Injection 위험이 있다.
- 게시글 수정 / 삭제에 작성자 권한 체크가 없다.
- 삭제 요청이 `GET /bbs/delete` 방식으로 처리된다.
- 자동 테스트 코드가 준비되어 있지 않다.
- `routes/bbs.js`에 기능이 집중되어 있어 유지보수성이 낮다.

## 8. 종합 평가

현재 프로젝트는 게시판 과제의 기본 기능 흐름이 상당 부분 복구된 상태이다. 세션 처리, 로그인 필요 기능 보호, soft delete, 조회수, 환경변수 분리, Bootstrap 5 기반 UI 개선까지 반영되어 시연 가능한 기반이 마련되어 있다.

다만 과제 요구사항을 완전히 충족하려면 비밀번호 암호화, 페이징, 댓글, 파일 업로드가 추가로 필요하다. 보안 측면에서는 SQL bind variable과 bcrypt 적용이 가장 우선이다.
