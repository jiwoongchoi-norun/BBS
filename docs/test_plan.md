# 테스트 계획

최종 업데이트: 2026-05-19

## 명령어 검증

```powershell
npm run verify:app
npm run lint
npm run format:check
```

선택 검증:

```powershell
npm run audit
npm run security:secrets
npm run security:semgrep
```

## 환경 준비

1. `.env.example`을 참고해 `.env` 작성
2. OracleDB 실행 확인
3. 신규 DB는 `@scripts/schema.sql`, `@scripts/sample-data.sql` 실행
4. 기존 DB는 `@scripts/migration.sql` 실행
5. `npm install`
6. `npm start`
7. `http://localhost:3000/bbs/list` 접속

## 보안 테스트

| 항목               | 절차                                 | 기대 결과                        |
| ------------------ | ------------------------------------ | -------------------------------- |
| SQL Injection      | `brdno=1 OR 1=1` 요청                | 잘못된 요청으로 차단             |
| 로그인 Injection   | ID/PW에 `' OR '1'='1` 입력           | 로그인 실패                      |
| 검색 컬럼 변조     | 허용되지 않는 검색 컬럼 전달         | 기본 검색 조건 사용              |
| 정렬 컬럼 변조     | 허용되지 않는 sort/order 전달        | 기본 정렬 사용                   |
| 숫자 파라미터 검증 | `brdno=abc`, `fno=abc` 요청          | 잘못된 요청으로 차단             |
| CSRF               | POST form에서 `_csrf` 제거           | 403 응답                         |
| XSS 표시           | 제목/내용에 HTML 입력                | 태그가 실행되지 않고 문자로 표시 |
| 세션 보호          | 로그아웃 후 보호 기능 접근           | 로그인 화면 이동                 |
| 탈퇴 계정 차단     | `LOGIN.OK = 0` 계정 로그인           | 로그인 실패                      |
| 다운로드 권한      | 다른 사용자의 첨부파일 다운로드 시도 | 403 응답                         |
| 경로 조작          | 파일 경로 traversal 시도             | 다운로드 차단                    |
