# BBS 과제 요구사항 요약

## 프로젝트

Node.js, Express, EJS, OracleDB를 사용한 게시판 과제 프로젝트이다.

## 기본 구현 범위

- Node.js / Express / EJS / OracleDB 연결 설정
- BBS 테이블 생성
- 게시글 목록
- 게시글 작성
- 게시글 읽기
- 게시글 수정
- 게시글 삭제 또는 비활성화
- Bootstrap 스타일 적용
- 제목 / 내용 / 작성자 검색
- 로그인
- 로그아웃
- 세션 처리
- 회원가입
- 회원정보 수정
- 비밀번호 암호화
- 조회수
- 페이징
- 댓글
- 파일 업로드

## 제출물

- 프로젝트 진행 및 사용 설명 문서
- 테이블 생성 SQL
- 게시판 모든 기능 화면 캡처
- 소스코드 정리본

## 가산점 후보

수업시간에 다루지 않은 기능을 추가 구현하면 가산점 가능성이 있다.

- SQL Injection 방지
- bcrypt 비밀번호 암호화
- 댓글 수정 / 삭제
- 대댓글
- 좋아요 / 싫어요
- 작성자 권한 체크
- 관리자 기능
- 입력값 검증
- Bootstrap UI 개선
- README 정리

## 작업 우선순위

1. 서버 실행 복구
2. DB 연결 복구
3. 게시판 CRUD 복구
4. 로그인 / 세션 / 회원가입 복구
5. 비밀번호 암호화 적용
6. 검색 / 조회수 / 페이징 구현
7. 댓글 구현
8. 파일 업로드 구현
9. 가산점 기능 구현
