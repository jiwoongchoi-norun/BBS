# BBS 과제 요구사항 요약

## 프로젝트
Node.js + Express + EJS + OracleDB 게시판 만들기

## 기본 구현 범위
- Node.js / Express / EJS / OracleDB connector 설정
- BBS 테이블 생성
- 게시글 목록
- 게시글 작성
- 게시글 읽기
- 게시글 수정
- 게시글 삭제 또는 비활성화
- Bootstrap 스타일 적용
- 제목/내용/작성자 검색
- 로그인/로그아웃
- 세션 처리
- 회원가입
- 회원정보 수정
- 비밀번호 암호화
- 조회수
- 페이징
- 댓글
- 파일업로드

## 제출물
- 프로젝트 진행 시 사용한 테이블 생성 SQL
- 게시판 모든 기능 화면 캡처
- 소스코드 압축

## 가산점
- 수업시간에 다루지 않은 기능 구현 시 추가점수 가능

## 우선순위
1. 서버 실행 복구
2. DB 연결 복구
3. 게시판 CRUD 복구
4. 로그인/세션/회원가입 복구
5. 암호화 적용
6. 검색/조회수/페이징
7. 댓글
8. 파일업로드
9. 가산점 기능
